# Новости Армении: сайт для хостинга

В папке три файла:

- `index.html` — страница сайта. Показывает новости, фильтры по рубрикам и датам выпуска, раскрытие полных текстов.
- `news.json` — все новости и тексты. Страница читает их из этого файла. Чтобы обновить сайт, достаточно заменить `news.json`.
- `README.md` — эта инструкция.

## Как посмотреть у себя на компьютере

Двойным щелчком `index.html` открывать нельзя: браузер не читает `news.json` с диска. Откройте папку в терминале и запустите:

    python3 -m http.server 8000

Затем откройте в браузере `http://localhost:8000`.

## Как разместить бесплатно на GitHub Pages

1. Создайте аккаунт на github.com и новый публичный репозиторий, например `armenia-news`.
2. Загрузите в него `index.html` и `news.json` (кнопка Add file → Upload files).
3. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Сохраните.
4. Через минуту-две сайт откроется по адресу `https://ваш-логин.github.io/armenia-news/`.

Свой домен, например `ваш-сайт.ru`, покупается у регистратора отдельно и подключается в тех же настройках Pages.

## Как устроен news.json

- `updated` — дата выпуска, `ГГГГ-ММ-ДД`.
- `lead` — главная новость вверху: `kicker`, `title`, `paragraphs`, `sources`.
- `digest` — короткая сводка справа от главной новости.
- `economy` — блок цифр: `note` и список `figures` со значением, подписью и источником.
- `stories` — лента. У каждой новости: `added` (дата добавления в ленту, `ГГГГ-ММ-ДД`), `date` (подпись даты события), `category` (Политика, Безопасность, Экономика, Общество, Регион или Культура), `title`, `summary`, `body` (список абзацев полного текста, может быть пустым), `source`.
- `sources` — общий список источников внизу страницы.

## Как обновлять каждый день

1. Новые новости добавляйте в начало списка `stories` с сегодняшней датой в `added`.
2. Старые оставляйте как архив. Записи старше 30 дней удаляйте.
3. Обновите `updated`, `lead`, `digest` и, если нужно, `economy`.
4. Загрузите новый `news.json` в репозиторий. Сайт обновится сам.

Для автоматизации через n8n сценарий должен по расписанию собирать новости, пересказывать их через модель, собирать новый `news.json` и записывать его в репозиторий GitHub (узел GitHub, операция Edit file). Перед публикацией имеет смысл просматривать результат: пересказ может ошибаться.

## Счётчик посетителей

Код счётчика Яндекс Метрики или Google Analytics вставляется в `index.html` в то место, где стоит комментарий про счётчик. Он учитывает всех посетителей. Чтобы видеть, какие новости читают больше, в Метрике можно настроить цель на клик по кнопке «Читать полностью».
